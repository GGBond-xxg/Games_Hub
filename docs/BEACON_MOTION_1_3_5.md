## 静态证据结论

默认背景是 **WAVES（波浪）**，并非移动的模糊光斑。设置仓库读取不到背景选项时使用 `WAVES`；背景分支映射、调用和形状生成方法相互印证。

| 项目 | 从当前 APK 得到的规格 |
|---|---|
| 组成 | 三层透明主题色波浪，底部填充，顶部是连续三次 Bézier 曲线 |
| 基准高度 | 上边界左右端点分别位于屏幕高度约 50%、60%、70% |
| 运动 | 两个控制点慢速往返改变曲线形状；三层错速产生层次 |
| 时长 | 三层单程 20、15、10 秒，Reverse 往返，完整周期 40、30、20 秒 |
| 缓动 | cubic Bézier `(0.4, 0, 0.2, 1)`，对应 FastOutSlowIn |
| 颜色 | 取当前主题颜色；深色透明度 0.25、0.23、0.21，浅色 0.30、0.28、0.26 |
| 填充 | 纵向渐变到透明；没有在这条波浪路径中发现图片素材或全屏模糊调用 |

以上是特定 APK 中可到达方法的静态观察，不等于已测得设备实际帧率、电量消耗或屏幕最终像素。原始类名受混淆影响，不能据此推断原作者源文件结构。设备当前选择可能覆盖缺省设置。

## GameHub 独立实现建议

1. 将 Glass / MIUIX 当前两团径向光斑改为主题色的三层曲线波浪，沿用现有“背景流动效果”开关；关闭时保留静态背景。
2. 使用 Compose Canvas 和缓存 Path 独立实现；动画值只在绘制阶段读取，避免每帧重组设置页、游戏列表和 Glass 控件。不要额外引入视频、位图动画或全屏模糊。
3. 采用约 10～20 秒单程和缓入缓出、往返运动；三层错速。颜色继续来自 GameHub 主题，确保浅色及深色文字可读。
4. 保留现有前后台生命周期停止机制；遵循系统动画缩放。切换后台、退出页面和关闭开关后不应保留持续绘制循环。
5. 手机横屏和平板逻辑宽度分别检查曲线、底部遮挡和玻璃材质；性能结论应由帧统计或追踪确认，不能仅凭代码声称流畅或省电。
