# v1.3.1 验证记录

## 修正内容

- 刮削字段旁的保存按钮现在立即提交当前配置，输入框与按钮统一为 56dp。密钥字段继续遮蔽，不进入备份或源码。
- TheGamesDB 使用官方 v1.1 搜索接口、平台目录与独立图片类型。PSP 编号修正为 13，原 38 是 Wii U。截图不再由封面替代，候选显示游戏标题。
- 批量补缺增加 TheGamesDB 元数据与图片来源，缓存类型/开发商/发行商字典。自动匹配限定平台和精确标题，地区版本采用固定优先级；“星之卡比”等系列词不会自动映射到某部续作。来源缺少的资料继续留空。
- Glass 按钮只绘制一层材质，取消重复边框和额外阴影；文本操作不再套大胶囊。返回、搜索和编辑页文字使用语义前景色。Glass 开关使用独立轨道与折射滑块，输入框使用玻璃表面。
- Glass 设置入口移至样式标题右侧，安全边距加减使用等大图标按钮；设置底部增加留白及操作间隔。搜索页保留一个查询输入框和一个搜索按钮，候选网格不超过四列。
- Glass / MIUIX 新增背景流动开关，默认关闭，跟随 Activity 生命周期暂停，M3 不显示此开关。持久设置兼容备份恢复。
- 设备测试发现系统 DNS 可能长时间不返回，连接超时不足以保护调用方。刮削请求增加整体时间限制和有界工作线程；单张候选图片失败后显示占位图，不无限转圈。图片下载限制体积和解码尺寸。

## 已完成检查

- `clean testDebugUnitTest assembleDebug assembleRelease`：成功；61 项 JVM 测试全部通过，其中包含显式启用的 TheGamesDB 在线测试。
- 官方接口实测：“星之卡比”、Kirby、Advance Wars、PSP 的 Dante's Inferno 均有候选；Advance Wars 的封面、截图能够下载解码，发行日期、类型、开发商、发行商完整解析。
- Android 批量流水线按标题测试：Advance Wars / 高级战争分别补齐独立封面、截图和四项资料；系列词“星之卡比”不自动错配。测试不提供 ROM，也不写 LauncherStore；测试图片自动删除。
- 最终 Android 在线复验曾遇到 `api.thegamesdb.net` 的 `UnknownHostException`，快速失败后重试在 9.5 秒内通过。设备 DNS 仍可能偶发不可用，整体超时用于限制等待，不能替代可用的网络。
- vivo V2310 / Android 15 / 1612×720：原始 300dpi 手机宽度及临时 160dpi 平板宽度的三主题 UI 回归各 15/15；测试后恢复原始密度。覆盖资料保存、批量确认/取消、主题切换状态、滑块、开关、输入框等高、字段保存回调、编辑与图片搜索页。截图使用内存测试条目，无真实密钥。
- 626 个翻译键在英语、简体中文、繁體中文中同步。新增 UI 文案已国际化；硬编码脚本报告的别名为游戏查询数据，旧有报告仍保留。
- `lintVitalRelease` 通过；应用 ID 保持 `com.bond.md3elauncher`，版本 1.3.1 / 131，API 24+，target API 36，ARM64/ARM32 包保留既有发布签名。

## 限制

- 完整 `lintRelease` 未通过：11 项既有错误，包括 `themes.xml:7` 的 cutout 属性 API 检查、FC/GBA 活动和旧重复文件调用 `ComponentActivity.dispatchKeyEvent` 的 RestrictedApi 检查，以及启动器所需 `QUERY_ALL_PACKAGES` 的权限策略检查。本次不改动模拟器控制器分发和包查询权限。
- 按用户补充要求采用在线游戏名测试，未执行用户完整 ROM 库的扫描与大规模刮削。ScreenScraper / SteamGridDB 未提供有效凭据，本轮不宣称它们的线上认证已通过。
- 资料语言与完整度取决于数据源。支持中文搜索不代表任意中文译名都可以自动、唯一匹配；手工选择具体作品可避免歧义。

在线测试只从进程环境或 instrumentation 参数读取临时密钥，默认跳过；不把密钥放入测试代码、文档或构建产物。JVM 在线测试需设置 `GAMEHUB_TGDB_TEST_KEY` 并显式重新运行测试，Android 测试使用临时 `tgdb_test_key` 参数。
