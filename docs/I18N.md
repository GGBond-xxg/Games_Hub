# Internationalization Rules

## Supported files

```text
app/src/main/assets/i18n/en.json
app/src/main/assets/i18n/zh.json
app/src/main/assets/i18n/zh-Hant.json
```

All three files must have exactly the same keys.

## Adding visible text

1. Add the key to all three JSON files.
2. Use the existing module naming style, for example `launcher.*`, `settings.*`, `edit.*`, `emulator.*`, `toast.*`.
3. Read it through `I18n.t(...)`, `I18n.short(...)` or the local translation helper already used by the file.
4. Do not add raw user-visible Chinese or English strings directly to active UI code.

Typical usage:

```kotlin
I18n.t(context, "common.save", "Save")
```

Placeholders must remain consistent in all languages.

## Fallback and language selection

- English is the default for non-Chinese systems.
- Simplified Chinese uses `zh.json`.
- Traditional Chinese locales use `zh-Hant.json`.
- Missing keys fall back through the existing `I18n` implementation; missing translations should still be fixed rather than relying on fallback permanently.

## Separate emulator processes

Internal emulators run outside the main process. Language state is written both to preferences and `filesDir/i18n_language_mode.txt`. Do not simplify this to SharedPreferences-only behavior.

Exiting an internal emulator closes its process so a later launch reads the newest language mode.

## Layout safety

- Buttons, tabs and bottom hints: one line with ellipsis where necessary.
- Explanations: bounded lines or a scroll container.
- Game/App names: one line with ellipsis.
- Canvas menus: use fitted-text helpers or intentionally short strings.
- Non-Chinese bottom shortcut hints should remain compact to prevent overflow.

## Checks

Validate key synchronization:

```bash
python scripts/check_i18n_keys.py
```

List likely hardcoded Chinese strings:

```bash
python scripts/check_i18n_hardcoded_text.py
```

The second script may still report legacy inactive files. Treat any new report in a modified active file as a regression unless it is a comment, parser alias or approved fallback argument.
