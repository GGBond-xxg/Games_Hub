# v1.3.4：图片搜索滚动与剩余 lint 审查

## 图片搜索

原页面把标题、说明、查询框和图片类型固定在结果上方，横屏启动器的上下栏进一步压缩候选网格。现在只保留返回/标题栏，其余内容都在同一个 LazyVerticalGrid 中：查询、类型和提示是跨列项目，可以随候选图一起滑走。保持最多四列，底部增加 18dp 留白；搜索按钮和键盘搜索动作都会收起键盘。下载失败提示也可以在已有候选图时看到。

预览和宫格字段、图片来源、查询匹配、批量补全策略没有更改。未添加嵌套纵向滚动容器，复用现有 M3 / Glass / MIUIX 控件适配层。

## 61 项警告复查

完整 lint 从 **0 错误 / 61 警告** 降为 **0 错误 / 37 警告**，没有新增 suppress、baseline 或全局忽略。

- 12 处 UseKtx：简单模拟器设置、手柄组合设置、语言偏好及游戏库备份事务采用内联 `edit`。仍只执行一次异步 apply；配置键、值、执行顺序保持一致。游戏库仍在同一事务内保留前一份有效快照，损坏文档不得覆盖快照。语言文件仍在偏好写入之后更新。
- 2 处 SetTextI18n：`circle` 与 `CodeBreaker/GameShark` 是输入/解析标识，不应翻译；将完全相同的值放入 `translatable="false"` 资源，界面解释仍用三语 JSON。测试断言它们的原始值。
- 5 张各密度 round PNG 与普通 PNG 的 SHA-256 完全相同，改为同名资源别名，删除重复文件。API 26+ 自适应 round XML 保留。此项消除了 5 个重复图片警告以及重复图片上的 5 个形状诊断；没有重新绘制图标，旧版图标形状问题仍由保留的 5 个诊断覆盖。

## 保护范围

模拟器变动仅限等价偏好写入和输入默认值资源。按键/触控事件分发、A/B/L3/R3 行为、存档槽、金手指重启恢复、进程退出、外部启动 Intent 和原生核心未修改。没有升级依赖，也没有增加 ROM、BIOS、密钥或商业素材。

设备测试使用独立 Compose 页面和随机 QA 偏好/语言目录，不改用户真实游戏库、手柄绑定或语言设置。没有 ROM 或实体手柄实玩；不能将这些回归测试等同于全部模拟器游戏兼容性验证。
